    Usuário

    Aparência e acessibilidade

    Contraste validado WCAG AA (>= 4,5:1) tanto no tema claro quanto no tema escuro.

    Sincronização via GitHub Token (opcional)

    Sem login Supabase ou token, tudo fica salvo gratuitamente neste navegador (isolado por perfil). Se você é dono do repositório no GitHub, pode colar um token com permissão em Contents e Actions para disparar o robô e gravar em estado.json.

    Conexão Supabase (Multiusuário na nuvem)

    O painel usa o Supabase configurado em supabase-config.js ou permite informar a URL e Anon Key do projeto para sincronizar marcações, clientes e publicações por usuário.

    Exportar ou importar meus dados

    Baixe uma cópia JSON do seu perfil, candidaturas, clientes e posts para levar para outro aparelho ou enviar de modelo para um amigo.
