    Quantos anúncios o robô leu em cada site, quantos entraram no painel e por que os outros ficaram de fora. Um site que bloqueou ou mudou aparece como Falhou, e não como zero vagas.

    Conferir uma vaga que eu achei

    Achou uma vaga por conta própria? Cole o link (e, se quiser, o cargo e a empresa), uma por linha. O painel diz se o robô viu essa vaga e, se ela ficou de fora, por quê. Assim dá para saber se falta um termo de busca ou um site.

    Salvar marcações em todos os aparelhos

    Sem isso, o que você marca fica só neste navegador. Cole um token do GitHub deste repositório com permissão de leitura e escrita em Contents e em Actions (Actions é para o botão Buscar vagas agora). Ele fica guardado só neste navegador.
